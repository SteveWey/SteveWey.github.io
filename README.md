# 个人博客

一个自用的个人博客，使用 Astro 构建，部署到 GitHub Pages。

- 线上地址：<https://SteveWey.github.io/>
- 仓库：<https://github.com/SteveWey/SteveWey.github.io>

## 技术栈

- Astro 7 静态站点
- Markdown + KaTeX
- 原生 CSS 与少量浏览器脚本
- GitHub Actions + GitHub Pages

## 本地运行

```bash
npm install
npm run dev
npm run check
npm run build
npm run preview
```

详细的项目结构、页面逻辑和内容维护流程见本地文档：

```text
docs/06-项目结构与维护.md
```
